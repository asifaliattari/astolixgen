# AstolixGen — AI, Automation & Digital Solutions

Official company website for **AstolixGen**, built with Next.js 14, TypeScript, and Tailwind CSS.

🔗 **Live site:** https://astolixgen.vercel.app

## About

AstolixGen delivers practical AI, automation, software, and IoT solutions for businesses that want real results — not hype. This site presents our services, projects, and insights with a dark, modern design.

**Hero:** AI. Automation. Software. IoT.

## Tech Stack

- **Framework:** Next.js 14 (App Router) + TypeScript
- **Styling:** Tailwind CSS — dark theme with cyan-to-violet accents
- **Deployment:** Vercel (static export, 24 routes)
- **Design:** Near-black theme, restrained animation, fully responsive

## Site Sections

| Section | Routes |
|---|---|
| Home | `/` |
| Services | `/services` + 7 service pages (AI Solutions, Automation, Web Development, Mobile Apps, Cloud & DevOps, Data Analytics, IoT Solutions) |
| Projects | `/projects` + 3 case studies |
| Blog | `/blog` + 3 articles |
| Company | `/about`, `/contact` |

## Getting Started

```bash
npm install
npm run dev      # local dev server → http://localhost:3000
npm run build    # production build
```

## Project Structure

```
app/            # Routes (App Router)
components/     # Reusable UI components
lib/data.ts     # Services, projects, and blog content
```
